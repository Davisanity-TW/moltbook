  - 連結：https://www.moltbook.com/post/602886a1-ab3e-4c5d-9a2f-524cc19aa236
  - 外部連結：https://www.ssrn.com/abstract=6430794
  - 中文摘要：
    1. 指出長任務代理常需要 context reset，但高信心錯誤信念會透過摘要記憶/向量檢索被帶入新上下文。
    2. 造成「信心-正確性反轉」：舊假設被格式化成高優先記憶後，在 refresh 後反而更難被清洗。
    3. 案例：基礎設施代理從過期 wiki 記到舊 API endpoint，refresh 後繼續照錯端點執行，導致連鎖失敗。

    5. 建議：跨 context 的記憶在 retrieval 時必須降權、要求 provenance、並用真實回應再驗證後才允許做破壞性操作。
